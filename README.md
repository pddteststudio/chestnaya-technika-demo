# «Честная-Техника» — независимый демонстрационный сайт

Современный адаптивный сайт-витрина для магазина, ремонта и выкупа смартфонов в Омске.

**Статус:** неофициальный демонстрационный концепт. Не связан с владельцем бизнеса и не является действующей торговой площадкой. Сайт заблокирован для индексации через `noindex,nofollow,noarchive`.

## Запуск локально

Требуется Node.js 20.19+ или 22.12+.

```bash
npm install
npm run dev
```

После запуска откройте адрес, который покажет Vite (как правило, `http://localhost:5173`).

## Проверка сборки

```bash
npm run build
npm run preview
```

Собранный статический сайт будет находиться в папке `dist/`.

## Размещение на Vercel

1. Загрузите содержимое этого архива в свой GitHub-репозиторий.
2. В Vercel нажмите **Add New, затем Project**, импортируйте репозиторий.
3. Выберите **Framework Preset: Vite** (определится автоматически).
4. **Build Command:** `npm run build`.
5. **Output Directory:** `dist`.
6. Нажмите **Deploy**.

Никакие переменные окружения не нужны. Бэкенд, сервер и платные API отсутствуют.

## Где менять данные

- `src/data.js` — название, телефоны, Telegram/VK/2ГИС, рейтинг, модели для демонстрации, список брендов, FAQ.
- `src/App.jsx` — разделы, формы и интерфейсы.
- `src/illustrations.jsx` — авторские SVG-изображения, иконки и иллюстрации.
- `src/styles.css` — весь адаптивный дизайн и анимации.
- `public/favicon.svg` — иконка вкладки.

## Рабочие функции

- Переходы по разделам и адаптивное меню.
- Фильтрация моделей iPhone. **Модели — примеры для запроса, не наличие и не товарный склад.**
- Подбор смартфона по бюджету, состоянию и приоритетам с копированием сформированного запроса.
- Пошаговая форма обращения в ремонт: бренд, модель, неисправность, описание. Интерактивная SVG-схема телефона меняется в соответствии с проблемой.
- Локальный предпросмотр фотографии для формы ремонта. Фото не загружается и не прикладывается к скопированному тексту.
- Форма для заявки на выкуп/обмен с формированием текста.
- FAQ-аккордеон, анимации появления, плавные переходы, внешние ссылки на официальные публичные контакты и карточку 2ГИС.
- Копирование в буфер обмена с резервным способом.

## Важно перед реальным запуском

1. Получите разрешение владельца компании и подтвердите бренд: в справочниках встречается также название «Device-Remont».
2. Перепроверьте телефоны, адрес, часы работы, Telegram, VK и рейтинг.
3. Уточните актуальные услуги, цены, гарантии, наличие устройств, историю ремонта и параметры каждого б/у телефона.
4. Замените демонстрационные иллюстрации товарными фотографиями, на использование которых имеются права.
5. Настройте законную обработку персональных данных и реальные заявки только с согласия компании и после необходимых юридических/технических проверок.
6. Удалите дисклеймер о независимом концепте и `noindex` **только после** согласования владельцем полноценного публичного сайта.
7. Уточните условия покупки и выкупа, подключения домена и передачи прав на сайт.

Данные форм нигде не сохраняются и никуда автоматически не отправляются. Функции обеспечивают подготовку текста, который пользователь самостоятельно копирует и отправляет выбранному адресату. Сайт не содержит вымышленных отзывов, гарантий, цен или остатков.
